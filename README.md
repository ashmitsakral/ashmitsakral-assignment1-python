# Retail Analytics Pipeline

## Project Overview
This Python project validates retail transactions, removes
invalid records, and creates a simple sales report.

## Requirements
- Python 3.10 or newer
- Visual Studio Code
- No additional Python packages

## Run the Project
Open the project folder in VS Code.
Open Terminal and enter:
    py main.py

## Run the Tests
    py test_pipeline.py

## Features
- Transaction validation
- Invalid date and negative revenue checks
- Data cleaning
- Total sales calculation
- Retention rate
- Best-performing branch
- Customer-tier breakdown
- Three simple tests
