## Project Description/Markdown Document 

# Why would someone find your project useful?
My project can be useful because it helps someone understand how to check 
retail transaction information and process of turning it into a cleaned out, 
accurate report. It also makes the process easier and more 
efficient for retail businesses. 

# What problem are you proposing to solve?
This project is being used to solve problems involving inaccurate transaction 
information and sales reports. The program checks for errors that could 
potentially impact the accuracy of the reports.

# What kind of data will your project work for?
The project works for retail transaction data and checks for reports that 
originates from cleaned data and transaction information.

# How will you make the project easy to build?
To organize the pipeline and transactions, the project is seperated into 
various python files that are each handling specific tasks. Reporter.py is 
responsible for showing the sales and report. Schema.py involves the 
transactions, transformer.py involves processing the records and validator.py 
involves checking data for no errors. It is simply how the information is 
stored and organized that makes it easier to connect it with the main program.
